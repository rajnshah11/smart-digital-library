# 📚 Interactive Learning Library

## 🚀 Goal 

Develop a cloud-based **digital library platform** for document management, user engagement, and data analytics using **AWS, FastAPI, and DynamoDB**.

## 📝 Description

Interactive Learning Library provides an efficient way to store, search, and analyze digital documents. Designed for educational institutions, corporate teams, and researchers, this platform enhances document accessibility, engagement, and data-driven insights.

### ✨ Key Features

✅ **Role-based Authentication**: Admin/User access control.  
✅ **Document Upload & Processing**: AWS Lambda + Textract for automated text extraction.  
✅ **Full-Text Search**: OpenSearch for fast and accurate document retrieval.  
✅ **Analytics Dashboard**: Gain insights on trends and user engagement.  
✅ **Scalable Backend**: FastAPI + DynamoDB for seamless performance.  
✅ **Modern Frontend**: React + Material-UI for an interactive user experience.  
✅ **State Management**: Redux for efficient data flow.
